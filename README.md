# CombeShop Backend 🛒

Simple eCommerce Backend built using Node.js, Express.js, and MongoDB.

## 🚀 Features

* User Authentication
* Product Management
* Razorpay Payment Integration
* Image Upload
* Email Support

## 🛠️ Tech Stack

* Node.js
* Express.js
* MongoDB
* Razorpay
* JWT

## ⚙️ Installation

```bash
git clone https://github.com/pyrahul26/combeshop-backend.git

cd combeshop-backend

npm install
```

## ▶️ Run Project

```bash
npm start
```
